# BIM Add-in Store: full setup from scratch

## 0. Architecture
```
Admin browser --HTTPS--> FastAPI (main.py) + SQLite + data/packages/<uuid>.zip
Modeller browser --login--> catalog (version-wise) --> bundle.zip (package.zip + installer + Install.bat)
Modeller PC: Install.bat -> Install-BIMAddinPackage.ps1 -> %APPDATA%\Autodesk\Revit\Addins\<year>\
Optional: BIMDeploy-Agent.ps1 polls /api/devices/* for managed/remote installs (needs device token)
```
Secrets (all in `server/.env`, generated by `manage.py init`):

| Secret | Used by | Purpose |
|---|---|---|
| ADMIN_TOKEN | scripts (Publish-Package.ps1), first-admin bootstrap | admin API fallback. Web admin uses login session instead |
| ENROLLMENT_TOKEN | agent first run | register a PC |
| DEVICE_TOKEN | agent polling | agent auth (shared, pilot-grade) |

User passwords: PBKDF2-SHA256 310k, per-user salt. Sessions: random token, only SHA-256 stored, 8 h TTL. Login lockout: 5 failures/15 min per IP+user.

## 1. Server (Windows or Linux, Python 3.11+)
1. Copy `server/` to the server, e.g. `D:\BIMStore\server`.
2. `run-server.bat` (Linux: `./run-server.sh`). First run creates `.venv`, installs deps, runs `python manage.py init` (creates `.env` with 3 random secrets), and starts uvicorn on :8000. It prints the LAN IP link to share; `0.0.0.0` is a listening address, not a shareable browser address.
3. Create the first admin (second terminal, same folder, venv active):
   `python manage.py create-admin --username admin` (prompts password, 12+ chars).
4. In an elevated PowerShell, run `./Configure-LAN-Access.ps1` once. This opens TCP 8000 only for the Private local subnet. Open the printed `http://LAN-IP:8000/` link on another PC connected to the same trusted Wi-Fi/Ethernet network; do not use `localhost` or `0.0.0.0` there.
5. Health: `http://SERVER:8000/health`.

## 2. HTTPS (required beyond a pilot)
Easiest: Caddy in front. `Caddyfile`:
```
store.yourcompany.com {
    reverse_proxy 127.0.0.1:8000
    request_body { max_size 600MB }
}
```
Bind uvicorn to loopback: `--host 127.0.0.1`. Internal CA cert must be trusted by modeller PCs.

## 3. Run as a service (Windows)
```
nssm install BIMStore "D:\BIMStore\server\.venv\Scripts\python.exe" "-m uvicorn main:app --host 127.0.0.1 --port 8000"
nssm set BIMStore AppDirectory D:\BIMStore\server
nssm start BIMStore
```
Back up `data\deployment.db` and `data\packages\` nightly. These files contain the admin accounts, users, sessions, packages, and jobs. Keep this `data` directory when restarting, updating, or moving the server.

## 4. Build a package (developer/admin PC)
Compile add-in for the target Revit year(s). Your `.addin` must have `<Assembly>` = your DLL name.
```
.\powershell\New-AddinPackage.ps1 -Id BIM.Exporter -Version 1.2.0 -Years 2024,2025 `
  -BuildDir .\bin\Release -AddinFile .\BIM.Exporter.addin -Assembly BIM.Exporter.dll `
  -DisplayName "BIM Exporter" -Description "Exports model data" -Scope user
```
Output `dist\BIM.Exporter-1.2.0.zip`:
```
manifest.json
payload/BIM.Exporter.addin
payload/BIM.Exporter.dll (+ dependencies)
```
One package per Revit-API generation. If 2024 and 2025 need different DLLs, publish separate IDs (`BIM.Exporter.2024`, `BIM.Exporter.2025`) or a single ID per year-range. Scope `user` = no admin rights needed.

## 5. Publish (admin, version-wise)
Web: Administration -> Publish add-in version -> choose ZIP (+ release notes). ID/version/years come from manifest.json.
Script alternative: `.\powershell\Publish-Package.ps1 -ServerUrl https://store... -AdminToken <ADMIN_TOKEN> -ZipPath .\dist\x.zip -ManifestPath .\manifest.json`
- Same ID + new version = new entry; old versions stay downloadable.
- Same ID + same version = rejected (409). Bump version.
- Revoke a bad version: Administration -> Published versions -> Revoke (hidden from modellers; Restore reverses).

## 6. Create modellers
Administration -> Create user (role Modeller, temp password 12+). Disable/reset password from the Users table.

## 7. Modeller flow (no agent needed)
1. Sign in. Filter by Revit year. Pick version.
2. Close Revit. Click **Download installer bundle**. Extract.
3. Double-click `Install.bat`.
   - Reads package.zip, validates paths and manifest.
   - Detects installed Revit years (`Program Files\Autodesk\Revit 20xx\Revit.exe`), intersects with manifest years.
   - Per-user: `%APPDATA%\Autodesk\Revit\Addins\<year>\<AddinId>\` + `.addin` copied to `...\Addins\<year>\`.
   - Machine scope: `%ProgramData%\Autodesk\Revit\Addins\<year>` (run as admin).
   - Previous install backed up as `<AddinId>.backup-<timestamp>`.
   - Override: `-RevitYear 2025` or `-ForceAllYears`.
4. Start Revit, accept the add-in load prompt (unsigned) or sign DLLs.

## 8. Optional: managed/remote install (agent)
1. On server: `python manage.py agent-config --server-url https://store.yourcompany.com > agent-config.json`
2. Copy `agent\BIMDeploy-Agent.ps1` + `agent-config.json` to the PC. Run `.\BIMDeploy-Agent.ps1 -Once` as admin to enroll.
3. Schedule at startup: `schtasks /create /tn BIMAgent /sru SYSTEM /sc onstart /tr "powershell -ExecutionPolicy Bypass -File C:\BIMAgent\BIMDeploy-Agent.ps1"`
4. Admin: assign device to user. Admin can Deploy remotely; modeller can Managed install on own device. Status shows Installed only after the agent reports.
Agent installs to `%ProgramData%\Autodesk\Revit\Addins\<year>` (needs SYSTEM/admin).

## 9. Tests
`python tests/smoke_test.py` and `python tests/test_store_v2.py`. Not covered: Windows PowerShell execution, real Revit load. Test in a VM with Revit first.

## 10. Production hardening backlog
Code-sign DLLs and set `approvedPublisherThumbprints` in agent config; per-device tokens; SSO/MFA; rate limiting at proxy; AV scan on upload; offsite backups; staged rollout.

## Troubleshooting
| Symptom | Cause / fix |
|---|---|
| 401 on upload with token | secrets in `.env` weak/placeholder (<24 chars or contains "replace-with"); re-run `manage.py init` |
| Bootstrap 409 | user exists; use `create-admin` |
| "No supported Revit found" | package years vs installed years; use `-RevitYear` / `-ForceAllYears` |
| Add-in not shown in Revit | `.addin` in `...\Addins\<year>\` top level, Assembly path absolute and existing, DLL unblocked |
| Upload 413 | raise `BIMDEPLOY_MAX_UPLOAD_BYTES` and proxy `max_size` |

## 11. One-click install (login -> Install now -> correct Revit folder)
One central server. Every PC uses only a browser + a one-time helper.
1. Server PC: set `BIMDEPLOY_PUBLIC_URL=http://SERVER-IP:8000` (or https name) in `server/.env`, restart. Firewall: allow TCP 8000.
2. Modeller PC, once: sign in -> Add-in Store -> **Download one-time setup** -> extract -> run `Setup.bat` (registers `bimstore://` for the current user, no admin).
3. Daily: sign in -> pick Revit year/version -> **Install now** -> browser asks to open the helper (allow) -> console downloads, verifies SHA-256, installs to `%APPDATA%\Autodesk\Revit\Addins\<year>`.
Security: link carries a 5-minute token; helper ignores any server URL in the link and uses only its local config.json; strict regex on the link.
Limits: Revit must be closed; `installScope: machine` packages need an elevated session (use `user` scope for modellers); browser cannot detect the PC, so the helper detects Revit itself.
